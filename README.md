# Clasificación de Frutas en JavaScript

Este es un proyecto simple en JavaScript que clasifica y cuenta las frutas en un array. Se utilizan diferentes estructuras de control como `for` y `while` para realizar la clasificación.

## Descripción

El programa toma un array de frutas, y clasifica cuántas veces aparece cada fruta (sandía, piña, manzana) en el array. Se implementaron diferentes métodos de iteración (`for`, `while`) para hacer la clasificación.

## Tecnologías utilizadas

JavaScript: Para la lógica de clasificación.

## Instalación y uso

Clona este repositorio:

git clone https://github.com/T0NYGUZM4N/clasificacion-de-frutas-for-while

Abre el archivo clasificacion-de-frutas-for.js

Interactúa con la clasificación de frutas según los criterios definidos.
